# 页境 · PageScape 使用说明

在思源笔记**文档正文中**插入子页面预览卡片，或直接操作 Canvas 中的文档、便签、分组和连线；也保留**独立 Canvas 页签**。

最低思源版本 **3.8.3**，插件版本 **0.7.0**，当前集成环境为思源 **3.8.8**。正在申请思源集市上架，审核通过前可通过 GitHub Releases 手动安装。


[返回项目首页](../README.md) · [更新记录](../CHANGELOG.md)

## 安装

1. 获取本项目构建生成的 `package.zip`。
2. 在思源工作空间的 `data/plugins/` 下建立 `PageScape` 文件夹，将压缩包解压到该文件夹。文件夹中应直接包含 `plugin.json`、`index.js`、`index.css` 等文件。
3. 重启思源，在插件管理中启用「页境 · PageScape」。

更新时，先关闭思源或禁用插件，再用新安装包覆盖这个插件文件夹中的文件。

从 0.6.x 的 `siyuan-child-cards` 升级时，先保存并关闭旧编辑页，停用旧插件，再启用 PageScape。通过命令面板的「迁移旧版插件 ID」检查清单并选择「备份并迁移」。原块备份在 `data/storage/petal/PageScape/plugin-id-backups/`，旧存储原件保留。只迁移已打开且未加密笔记本中的三种旧版自定义块；保留块 ID、正文、布局和引用。其他笔记本打开后可重新检查。存在存储冲突时停止，重复迁移会识别已导入文件并保留其后续修改。

## 使用

在文档正文空白行输入 `/子页卡片`、`/cards` 或 `/childcards`，选择「子页卡片 · Child Cards」。也支持 `/childpages`、`/children`、`/gallery`。也可以使用编辑器工具栏的卡片按钮，或在命令面板搜索「插入子页卡片」或 `Insert Child Cards`。

- 默认按思源文档树顺序显示直接子页，过滤隐藏文档。
- 点击卡片标题打开子页；预览文字可以选择、复制，内部块引用可以点击打开。
- 空白子页显示它的下级页面链接；没有内容也没有下级页面时显示「暂无内容」。
- 卡片块移动到其他文档后，会以新文档为来源重新读取子页。
- 通过卡片块的「设置」调整列数、预览高度、图片与自动更新。每个卡片块独立保存设置。
- 子页较多时先加载 20 张，点击「加载更多子页」继续读取。

默认布局为三列，末行自动填满；窄屏显示单列。预览实际超出设定高度时才显示底部渐隐。

## 自动更新

自动更新默认开启。插件监听文档保存和文档树变化，对短时间内的变化合并约 500 毫秒后处理：正文变化更新对应卡片，新增、移动、删除、重命名和排序变化重新核对子页列表。

切回思源窗口或文档时会补充检查；右上角的刷新按钮可以手动重新读取。刷新速度还取决于思源保存与本地读取耗时，插件不使用定时轮询。

## Canvas 画布

点击顶栏的画布按钮，在弹出的菜单中选择新建或打开已有画布。也可以在命令面板搜索「新建 Canvas 画布」/ `New Canvas`，或在正文输入 `/newcanvas` 开始新建；「打开 Canvas 画布」/ `Open Canvas` 和 `/canvas` 用于打开已有画布。

新建时输入画布名称，并选择笔记本根目录或某个父文档作为保存位置。系统会建议「新画布」「新画布 2」等尚未使用的画布名称，创建前可修改；名称不能为空，最多 300 个字符。取消对话框不会创建文档。

每次新建都会创建独立文档并在新 Canvas 页签打开，已有 Canvas 页签及内容保留。再次打开已有画布时复用它已打开的页签；从文档概要的「打开 Canvas」或命令「打开本文档 Canvas」打开时，定位到该文档对应的页签。

每张 Canvas 对应一个普通思源文档，文档正文中的 `canvas-document` 自定义块保存布局 JSON。桌面端平常打开这个文档，就会显示可直接操作的画布；画布前后可继续写普通正文。正文画布固定绑定其来源，不能通过下拉框切换成另一张画布。「打开 Canvas」进入同一画布的独立页签；独立画布工具栏的「打开所属文档」可返回。正文内「另存副本」会选择保存位置并独立打开副本，原文档仍显示原画布。移动端继续显示概要和缩略图。原有 `/cards` 正文子页卡片继续独立使用。

### 在任意文档中插入或引用画布

在正文位置输入 `/embedcanvas`、`/inlinecanvas`、`/嵌入画布`，或使用工具栏的「插入或引用 Canvas」和同名命令。可以选择已有画布，也可「新建并插入」，先选择新画布的名称及保存位置。

插入的是 `canvas-reference` 引用块，保存来源画布的文档 ID；布局仍保存在来源文档中。多篇文档引用同一画布时共用卡片和布局，修改会反映到各处。移动或复制引用块继续指向同一个来源；删除引用块不会删除来源画布。引用失效时显示错误，不会新建空画布覆盖来源。一个普通文档可插入多张画布；每个来源画布文档仍只保存一个布局块。

### 搜索、导航与工具栏

默认显示紧凑工具栏。「更多工具」展开附件、跟随子页、排列、设置、重载、副本与导入导出操作；选择在本机记住。

「搜索画布」搜索卡片标题、便签文字、文档 ID 和已经加载的文档预览。Enter 定位匹配项，上下方向键切换；画布空白处按 Ctrl+F 也可搜索。不会把未加载的原文全文下载到搜索框。

右上角小地图可点击、拖动或用方向键移动视口，工具栏可切换显示。用「跳到分组」定位某个分组；右键连线可「沿连线跳转」，也可明确跳到起点或终点。搜索和反向引用定位到折叠成员时，会展开所属分组；只读时定位到可见的折叠分组。

### 子页自动跟随

在「更多工具」点击「跟随子页」，选择父文档。新增的直接子页会自动添加为卡片，已有卡片保留位置、尺寸与连线。原文保存、文档树变化及切回窗口时补充检查；没有持续的后台轮询任务。

子页移出或删除时，跟随卡片标为「已移出子页」，不自动删除内容或连线。手动移除的跟随卡片会记入排除列表，后续刷新不会重新添加；重新选择跟随父文档会清空该列表。「停止跟随」保留当前卡片。父文档暂不可读或列表请求失败时保留原布局。来源画布自身不会作为自己的子页卡片加入。

### 分组折叠与连线布局

点击分组标题旁的「收起 / 展开」，或右键折叠分组。收起时隐藏成员并将跨组连线显示到分组边缘；展开后恢复成员位置和原连线端点，展开尺寸不会丢失。移动折叠分组仍会带动其成员。

「更多工具 → 对齐 / 排列」增加「树形布局（向右）」和「层级布局（向下）」，按连线层次排布。选中卡片时排列选中项，未选中时排列顶层卡片；分组作为整体带动成员。循环连线和不相连的卡片可以保留，不会因无法形成严格树结构而删除关系。

### 模板和反向引用

「模板」提供概念与公式推导、论文阅读、模块依赖三种内置结构。「添加到当前画布」追加新卡片与连线，使用独立 ID，不替换已有内容。

「将当前画布保存为模板」在同目录创建名为「模板：名称」的普通画布文档，并登记模板标记。模板保留便签、布局、原文及附件引用，附件沿用原生登记；自动跟随设置不复制到模板。可直接打开模板文档编辑；应用模板复用文档和附件引用，不复制原文。「从模板列表移除」只清除模板标记，保留该画布文档与附件。

在原文编辑器工具栏或命令面板使用「画布反向引用 · Canvas References」，可以查看已打开笔记本中引用本文档的画布，点击定位到具体卡片。画布工具栏的「引用位置」检查选中文档卡片；未选中文档卡片时检查当前画布被哪些文档嵌入。结果来自插件实际布局和引用块，不等同于思源原生反链统计；暂不可读的画布会在结果中提示。

命令「将当前文档子页导入 Canvas」/ `Import Children to Canvas` 会把当前父文档的直接子页加入已打开的画布；重复导入跳过已有文档。

### 内容与编辑

- 「添加文档」按标题或路径搜索，支持多选；也可拖入文档树中的文档、文档页签，或粘贴思源文档链接。双击标题打开原文档，原文变化会更新预览，保持卡片位置和尺寸。
- 文档预览默认只读。在独立 Canvas 页签中，双击预览区或右键选择「在卡片内编辑」，会打开思源原生编辑器，**此时修改会写入原文档**。点击「结束编辑」、空白区域或按 Escape 退出。正文画布中双击文档卡片打开原文档；思源自定义块不支持嵌套原生编辑器，便签仍可直接编辑。
- 右键文档卡片可「限制到标题或块」，输入 `#标题` 或 `#^思源块ID`；找不到片段时保留引用并提示。也可「替换文档」，保留节点位置、尺寸和连线。
- 便签支持 Markdown 阅读与文本编辑。双击便签或点击「编辑」输入内容；右键「转换为思源文档」可选择名称和保存位置，成功后用文档引用替换原便签。
- 「添加附件」、拖放文件或粘贴图片可上传图片、PDF、音频和视频。图片显示预览，音视频提供播放器；PDF 和其他附件通过打开入口查看。每次支持 1–20 个媒体文件，单文件不超过 200 MB。
- 右键「替换附件」可更换媒体并保留卡片位置、尺寸和连线。导入画布中的待关联文件，可选择「导入待关联附件」上传媒体，或「关联思源文档」选择已有笔记，沿用原节点与连线。
- 「添加网页」、拖放或粘贴 HTTP/HTTPS 地址可创建网页卡片。网页默认显示地址与外部打开入口，点击「网页预览」才加载受限 iframe；站点自身的嵌入策略可能禁止预览。

### 整理与导航

- 拖动卡片标题移动，拖动右下角调整大小；Shift+拖动可限制移动方向，Shift+调整大小保持比例。
- 拖动空白处、按住空格拖动或中键拖动可平移；Ctrl+滚轮或空格+滚轮缩放。按钮支持恢复 100%、适应全部和适应选择；快捷键分别为 Shift+1、Shift+2。
- Shift+点击多选，Shift+空白处拖动框选，Ctrl+A 全选。支持 Ctrl+C/Ctrl+V 复制粘贴节点、Ctrl+D 复制一份、Ctrl+Z 撤销、Ctrl+Shift+Z/Ctrl+Y 重做；便签或原生编辑器内优先使用文本编辑操作。
- 「对齐 / 排列」提供边缘与中心对齐、水平/垂直等距，以及行、列、网格排列。设置中可切换网格吸附、对象吸附和画布只读。
- 「分组」组织所选节点；也可右键空白处建立空分组。拖动组标题带动成员，节点移入或移出分组后更新所属关系。分组可设置背景图片与填充、等比、平铺方式。
- 从卡片上、右、下、左端口拖出连线，或用「连线」模式依次选择节点。双击连线编辑说明；选中后可拖动端点重新连接，右键可反转方向、设置无箭头/单向/双向，或删除连线。连线拖到空白处会新建并连接便签。
- 节点和连线支持预设颜色及自定义十六进制颜色。「移除」与 Delete/Backspace 只移除画布节点和关联连线，不删除被引用的文档。

### 布局交换与图片导出

「导入 .canvas」读取 JSON Canvas 1.0 文件，选择保存名称和位置后创建独立画布文档与页签，不覆盖当前画布。「导出 .canvas」保存文字、文件、网页、分组、位置、尺寸、层叠顺序、颜色、背景与连线方向等布局信息；思源特有设置通过扩展字段保留。小数几何坐标在标准文件中取整，尺寸至少为 1 像素。

思源文档引用仍以 `siyuan://blocks/<文档ID>` 文件引用及扩展元数据保存，**不会自动转换为 Obsidian Markdown 文件**。Obsidian 的外部附件也不会随 `.canvas` 文件打包；原相对路径会保留并显示待导入提示，需要另行导入资源并重新关联或替换卡片。布局交换不等于直接、完整的 vault 兼容；不支持的数据格式或不安全路径会明确报错。

「导出 PNG」生成画布中卡片、文字和连线的图片。不可读取的媒体、跨域读取限制或仍打开的网页 iframe 会明确报错，保留原画布；可先关闭网页预览，再导出包含地址的卡片。PNG 不包含完整源文档，文档卡片导出的是画布中的预览内容。

### 保存与使用范围

修改约 450 毫秒后自动保存到所属文档的画布块。布局包含节点位置与尺寸、文档引用、便签、媒体引用、分组、连线、视口和设置；被引用文档的全文仍保存在原文档中。

本地媒体同时登记为所属文档的原生附件引用，供思源资源管理与导出识别；替换或移除时同步更新登记，文件本身仍由思源管理。

保存前重新读取所属文档版本；检测到其他窗口已修改时，保留本地草稿并提示另存副本或重载。「重载」会先把尚未保存的修改保存为同父目录的副本，再读取最新版本。关闭画布时会尝试完成保存；网络失败时保留同窗口恢复草稿。画布随所属文档参与思源同步和文档历史，历史粒度由思源决定，**不能保证每次拖动都有独立历史版本**。文档引用保存在布局 JSON 中，**不能保证出现在思源原生反链统计中**。插件的版本检查不提供跨设备同时写入的原子锁，建议同一画布依次编辑。

Canvas 主要面向桌面端与桌面浏览器，当前保存位置支持已打开的未加密笔记本。文档预览最多显示开头 10 个非空内容块；全文编辑使用原生编辑器。移动端操作、Obsidian Bases、其插件及整套应用生态不承诺等同；当前也不提供手绘工具。

### 迁移旧版 JSON 画布

旧版 Canvas 文件原件仍在思源工作空间 `data/storage/petal/siyuan-child-cards/` 下，文件名为 `canvas-*.json`，索引为 `canvas-index.json`。先执行「迁移旧版插件 ID」将这些文件复制到 `data/storage/petal/PageScape/`，再执行下方的旧 JSON 画布转文档流程；旧目录保留。

使用画布工具栏的「迁移旧画布…」，或命令「迁移旧 Canvas 为文档 · Migrate Canvas to Documents」，选择新画布文档的保存位置。迁移会先在插件存储目录下的 `canvas-backups/<runUUID>/` 保存原始文件，并核对备份字节与 SHA-256；校验通过后才创建画布文档，再校验迁移后的布局。

同目录的 `canvas-migration.json` 记录备份校验、进度和旧画布 ID → 新文档 ID 的映射，供中断恢复和再次执行时核对。原始 JSON 和备份都保留；迁移入口不会删除原件，遇到损坏数据或校验不一致时显示错误，不用空画布覆盖原内容。

首次迁移选择的位置会记入清单，恢复时沿用该位置。创建请求结果不明、且无法读取目标文档时，迁移会停止并保留进度；由于思源的“块不存在”也可能表示索引或笔记本不可用，插件不会据此重新创建文档。请先恢复目标文档可读状态，再继续核对迁移。

## 正文子页卡片的支持范围

支持开头最多 10 个非空内容块的只读预览，包括段落、标题、列表、引用、表格、代码、公式和图片。代码高亮与公式使用思源自身的渲染能力，渲染失败时仍保留可读文本。

数据库、挂件、白板、嵌入查询、自定义块、HTML、音视频等复杂内容显示「打开文档查看」占位，避免递归加载。首版展示一层子页，不提供卡片内编辑、全文展开、跨目录筛选或卡片更多菜单。

图片按笔记中的原地址加载，可在当前卡片块设置中关闭。主题颜色跟随思源。桌面端是首版主要验收环境，移动端还需结合实际设备验证。

正文子页卡片及 Canvas 的默认预览只读取被引用文档；移动、排列或移除节点不会修改原文。Canvas 中明确选择「在卡片内编辑」会通过原生编辑器修改源文档，「转换为思源文档」会创建新文档。正文卡片只在插入或调整设置时写入当前块，Canvas 布局另存于其所属文档。停用或卸载插件后，文档中的配置和布局仍会保留。

## 本地开发

需要 Node.js 22 或更高版本与 npm。在项目目录运行：

```sh
npm ci
npm run typecheck
npm test
npm run test:preview
npm run build
```

`npm test` 检查配置、事件解析、共享预览缓存及 Canvas 模型、JSON Canvas 互通与安全边界、存储冲突、文件接口错误处理和 JSON 迁移备份与恢复；`npm run test:preview` 在浏览器中检查预览隔离与渲染器调用。

`npm run test:canvas-features` 在隔离编辑器中验证 0.6.0 的共享引用、在正文新建并嵌入、子页自动跟随与失败保护、搜索与小地图、分组折叠、连接布局、模板的原生附件登记、反向定位、多视图延迟保存以及失效引用保护。

正文卡片集成测试为 `npm run test:ui`，文档画布集成测试为 `npm run test:canvas-documents`，多窗口冲突、损坏数据和删除保护为 `npm run test:canvas-safety`，新建名称、位置及页签定位回归为 `npm run test:canvas-create`。`npm run test:canvas-inline` 检查正文内拖动、便签焦点、连线、保存与重开、同一画布的独立视图、正文保护与卸载。`npm run test:canvas-parity` 检查扩展交互、真实上传、原生编辑、转换和 `.canvas` 导入等路径；`npm run test:canvas` 保留文档画布与安全两项集成测试。旧 JSON 存储与迁移逻辑由 `npm test` 验证。

集成测试需先构建，并用思源 3.8.8 内核在本项目 `.test-workspace` 目录启动独立服务：端口 `6807`，访问授权码 `child-cards-isolated-test`。目录须预先建立，内核 `serve` 的 `--wd` 指向已安装思源的 `resources` 目录。测试会校验工作空间路径，然后只在这个独立目录创建测试笔记、启用插件，验证卡片和 Canvas 的交互、保存、更新、冲突及卸载；拒绝写入用户工作空间。浏览器测试默认使用本机 Microsoft Edge。

构建输出在 `dist/`，可安装压缩包为项目根目录的 `package.zip`。测试和构建不访问或修改你的思源笔记。

源码使用 TypeScript、原生 DOM 和局部 CSS，无前端框架依赖。
